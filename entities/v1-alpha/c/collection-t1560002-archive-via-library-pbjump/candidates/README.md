# T1560.002 — Archive via Library

> An adversary may compress or encrypt data that is collected prior to exfiltration using 3rd party libraries. Many libraries exist that can archive data, including [Python](https://attack.mitre.org/techniques/T1059/006) rarfile, libzip, and zlib. Most libraries include functionality to encrypt and/or compress data.
